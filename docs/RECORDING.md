# Recording the Medusae demo

Target: 45–90 seconds, 1920×1080 if available, MP4. Use a readable terminal font and hide unrelated windows and notifications. Keep API keys, private data, and account details out of the recording.

| Time | Show |
| --- | --- |
| 0–8 s | Animated Medusae home screen. Let the portrait and falling characters breathe. |
| 8–18 s | Continue a prepared public-repository chat. |
| 18–35 s | Ask one focused question. Show the answer and actual model name. |
| 35–50 s | Open `/map`, then rotate and zoom the knowledge graph. |
| 50–65 s | Double-click a node, move/resize the source window. |
| 65–80 s | Switch to Architecture, select a connected component, then show a follow-up in browser chat. |

Use an already indexed small repository to avoid spending the demo cloning. If you cut out a model wait, label that cut; do not imply accelerated footage is real-time. A silent demo is fine. Save the original recording outside the repository and pass its path to the assistant.

The [README demo](../README.md#demo) uses the project owner's recording from 29 September 2026. A short animated preview links to the trimmed video hosted on the v0.1.0 release. The original recording stays outside Git history. See [media notes](media/README.md) for the edits.
